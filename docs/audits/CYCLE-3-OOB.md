## Process changes and costs
- The gate stages only named new files and refuses a tree that changed while `verify` ran (FND-0064).
- Tests cannot touch a database that is not named `*_test` (FND-0059).
- A release is tagged only after its commit's CI is green, and the release gate checks carried items' revisit events (FND-0063, FND-0065).
- Screenshots: full sets only at phase and release candidates (DEC-0034).
- Cost: five reviewer agents (≈ 1.05 M tokens), one remediation wave per surface, one re-verification and a corrective demo release.
