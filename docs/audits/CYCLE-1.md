## Process changes and costs
- `verify` now includes the API e2e suite (≈ +6 s locally) so CI corroborates HTTP contracts; vitest hook timeouts raised for cold PGlite starts.
- Every case mutation follows the lock-in-transaction rule (DEC-0017); reviewers should treat any new `this.db.update(supportCases)` outside `mutate()` as a defect.
- Customer-facing contracts are explicit projections (DEC-0015): adding a field to `CaseSummary` requires deciding whether customers may see it.
- Environment facts (OS, git author) are recorded in `CLAUDE.md`/handoff as observed facts, not assumptions.
- Cost: five reviewer agents (≈ 1.0 M tokens), remediation and re-verification ≈ one session. The Owner's «Continua hasta el final sin parar» instruction covered the audit.
