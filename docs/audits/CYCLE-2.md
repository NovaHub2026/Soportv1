## Process changes and costs
- Commits go through `scripts/gate-commit.sh` (`npm run gate`) and a `pre-commit` hook runs `check:context`; CI builds the applications after `verify`.
- `check-context` fails on PLACEHOLDER tokens and requires a cycle-specific ledger echo; ledger counts have one owner (the ROADMAP table).
- Configuration inputs that a program later trusts (time zones, intervals) are validated at the boundary and fail closed downstream — reviewers should treat an `Intl`/timer input without validation as a defect.
- The Orbit boundary answers "could not ask" distinctly from "no data" on every method (`OrbitLookup`), including contact e-mail.
- Cost: five reviewer agents (≈ 1.0 M tokens) plus a fresh-clone verify; remediation in three waves (API/shared, web, process/docs) and one re-verification ≈ one session. The Owner's «Continua automáticamente hasta finalizar todos los ciclos» instruction covered the audit.
